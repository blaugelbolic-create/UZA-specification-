# UZA-specification-
Die Universelle Zusammenhangsarchitektur (UZA) ist eine versionierte, typisierte und semantisch validierte Grammatik zur reproduzierbaren Erfassung, Analyse, Orientierung, Gestaltung und kontrollierten Weiterentwicklung komplexer, dynamischer, verschachtelter und interagierender Zusammenhänge. [Zitiert aus der Spezifikation, S. 61]
